# Project description

Marketing Campaign Effectiveness and Lead Prioritization brings campaign reporting and lead routing into one view. Rather than stopping at click-through rates or cost per lead, it follows each lead from first-touch campaign through qualification, sales acceptance and won deal. A time-based model test ranks likely wins, while a multi-touch comparison shows how first-touch, last-touch and linear attribution can give different answers to the same question.

The interactive dashboard is built around five chapters: budget and outcomes, funnel quality, the lead queue, attribution, and a budget-shift sandbox. The supporting files include synthetic source data, a scored lead list, reproducible Python analysis, SQL examples, charts, a business report and a SQLite database.

**Scope:** portfolio demonstration using synthetic B2B campaign and CRM data. No real customer records are present. Campaign performance is descriptive; the project does not claim to prove incrementality.
