# Analysis outputs

The CSVs in this folder are generated by `python scripts/run_analysis.py`.

- `campaign_summary.csv`, `channel_summary.csv`, `monthly_performance.csv`, `campaign_monthly_performance.csv`: campaign, channel and time-based performance rollups.
- `scored_leads.csv`: full ranked lead table, score bands and recommended next actions.
- `model_holdout_metrics.csv`, `score_deciles_holdout.csv`: time-based model evaluation.
- `attribution_summary.csv`, `attribution_by_cohort_and_first_campaign.csv`, `attribution_credit_shift.csv`: first-touch, last-touch and linear credit comparisons, including the amount of credit that changes channel bucket between first-touch and last-touch.
- `channel_quarter_summary.csv`: quarterly revenue-to-spend ratios.
- `illustrative_budget_shift.csv`: a simple planning scenario, not a forecast.
- `dashboard_data.json`: aggregated data embedded in the interactive dashboard.
- `dashboard.html`: standalone dashboard page; root `index.html` is the copy intended for GitHub Pages.
- `analysis_summary.md`: narrative reading of the generated outputs.

Treat every result as descriptive synthetic evidence. Ratios do not prove incrementality or profit.
